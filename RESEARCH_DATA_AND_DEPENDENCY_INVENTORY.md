The project’s older stage records remain historical assessments; this inventory does not change commercial, redistribution, or deployment approvals. ERA5-Land request archives remain excluded. Open-Meteo’s non-commercial setting is an operator opt-in, not a licence determination.

The Kerala Ecostat portal exposes an EARAS dataset catalogue and downloadable annual-statistics reports, but the reviewed publication page did not state a reuse licence. Until official reuse terms and the exact Idukki black-pepper fields are confirmed, these are source leads rather than training-ready data. The data.gov.in endpoints tested in this phase returned HTTP 403 to the research browser; they are not counted as an accessible integrated source.

## Runtime and research dependencies

| Package / service | Version or configuration | Licence / role | RAM notes |
|---|---|---|---|
| FastAPI / SQLAlchemy / PostgreSQL driver | Versions pinned in `backend/requirements.txt` | MIT / MIT / LGPL-family client components; API and existing database access | Existing application stack; no new database service required by research features. |
| pypdf | `5.1.0` in `backend/requirements.txt` | BSD-3-Clause; local PDF text extraction | Upload capped at 10 MiB, 500 pages and 1 million extracted characters. Text extraction remains the default. |
| pypdfium2 / pytesseract | Optional pins in `backend/requirements-research-ocr.txt` | Apache-2.0 / Apache-2.0; local PDF page rendering and Tesseract wrapper | OCR is opt-in, limited to 50 scanned pages and 4 megapixels per rendered page, with a 30-second per-page OCR timeout. | NumPy / pandas / scikit-learn | Pinned in `backend/requirements-research.txt` | BSD-3-Clause / BSD-3-Clause / BSD-3-Clause; CSV handling and bounded Random Forest regression/classification baselines | Training is capped at 20 MiB and 50,000 rows, one worker and 30 features. | Ollama (optional) | Locally installed Ollama server and an already-pulled model; `OLLAMA_BASE_URL` and `OLLAMA_MODEL` | Review the server and exact model licence independently. Qwen2.5 0.5B is one candidate (Apache-2.0, about 398 MB per the Ollama library); no model has been pulled or benchmarked here. Local HTTP only; AgroSense does not download a model. | Not required. If absent or unavailable, retrieval returns ranked excerpts with citations instead of failing. The 398 MB file size is not a RAM guarantee; check actual memory use on the 8 GB PC before extended use. |

Install the research set from `backend` with `python -m pip install -r requirements-research.txt`. The file includes the regular backend requirements and does not include PyTorch or XGBoost.

For scanned-PDF OCR only, additionally install `python -m pip install -r requirements-research-ocr.txt` and install the Tesseract OCR executable separately. Without both, leave the OCR checkbox off; normal PDF text extraction and retrieval continue to work.
