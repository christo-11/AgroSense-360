# AgroSense-360 Stage 22 Official Data Request Drafts

**Status:** Draft documents only  
**Not sent:** No organization has been contacted  
**Purpose:** Future, non-commercial research and professional portfolio use, with separate ML-training consideration

## Common request elements

Every request should ask for:

- Exact dataset/publication name and version/revision.
- Publisher and responsible custodian.
- Official URL/resource ID/API identifier.
- Geographic and temporal coverage.
- Data dictionary and units.
- Frequency, update schedule and revisions.
- Attribution/citation language.
- Research and portfolio reuse.
- Redistribution and derivative-work permissions.
- Commercial-use scope.
- Potential use for research ML training.
- Privacy and personal/farm information controls.
- Quality flags, known limitations and acquisition format.
- Written confirmation of terms or a link to the applicable resource-specific licence.

No request should use the words "approved", "authorized" or "cleared" unless the responding owner provides explicit written confirmation.
